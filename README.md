Professional static showcase based on the CV description:
- medical image classification

- healthcare cost regression

## Publish on GitHub Pages
1. Create a new public repository named `ml-deep-learning-projects`.
2. Upload **all files in this folder to the repository root** (do not upload the ZIP itself).
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`.
7. Save.

Expected URL:
`https://YOUR-USERNAME.github.io/ml-deep-learning-projects/`
